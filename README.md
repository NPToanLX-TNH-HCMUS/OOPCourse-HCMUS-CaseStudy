## Quick Start

> [!NOTE]
> Each case is a single-header implementation. Just compile `main.cpp` — no build system required and run output file to test my code as a client, all the implementations are in `.hpp` files. Feel free to change code in `main.cpp` for better testing. ༼ つ ◕_◕ ༽つ

> [!NOTE]
> In each case, there is also a `REPORT.md` file to answer discussion questions, explaining implementation choices, architecture, design patterns, etc..... and Mermaid (Class Diagram) files to show relationships among classes.
